================================================================================
KEY FINDINGS
================================================================================

1. MOIRAI20-SMALL IS THE CLEAR WINNER
   - Wins on 3/7 fields (barometer, hub_voltage, irradiance)
   - Lowest average MASE (0.461) — 16% better than runner-up Toto-22m
   - Best average rank (2.57) — most consistent performer
   - Fastest neural model at ~19ms/call (11x faster than TimesFM)
   - Best probabilistic calibration (lowest average CRPS: 5.91)
   - Only 200M params vs TimesFM's 200M — same size, vastly better results

2. TOTO-22m-MV IS A TEMPERATURE SPECIALIST (AND A TRAP)
   - Amazing on temperature (MASE 0.308, best overall single result)
   - CATASTROPHIC on multivariate fields: humidity_prec (1.77), barometer (1.63),
     wind_direction (1.64) — all worse than seasonal-naive
   - The "poisonous field" detection is working correctly — it excludes bad sensors
     from the multivariate batch, but when too many are excluded, the mv path fails
   - Verdict: Use ONLY for temperature, or when you know all sensors are clean

3. TIMESFM IS THE BIGGEST DISAPPOINTMENT
   - 200M parameters, 10x slower than Moirai (~212ms vs ~19ms)
   - Never wins a single field
   - Consistently middle-of-pack accuracy
   - The transformers fallback path is working but the model just isn't competitive
     on this ECCC dataset

4. CHRONOS2-SMALL IS THE WORST NEURAL MODEL
   - 48M params but worse average MASE (0.740) than seasonal-naive (0.768)
   - Terrible probabilistic calibration (CRPS 14.34 average — 2.4x worse than Moirai)
   - Only redeeming quality: it's fast (~22ms) and doesn't crash

5. PERSISTENCE IS A LANDMINE
   - Looks great on 6/7 fields (often 2nd or 3rd place)
   - Completely fails on irradiance: MASE = 160.7 (160x worse than neural models!)
   - Why? Persistence predicts the last value forever. At night, irradiance = 0.
     When sunrise happens, persistence stays at 0 while actual GHI shoots up.
   - Verdict: NEVER use persistence for solar/irradiance forecasting

6. SEASONAL-NAIVE IS THE SAFEST HEURISTIC
   - Beats ALL neural models on wind_direction (MASE 0.601)
   - Never catastrophically fails
   - Zero latency, zero dependencies
   - Verdict: Keep as a sanity-check baseline in production

================================================================================
PRODUCTION RECOMMENDATIONS
================================================================================

SCENARIO A: "I want ONE model to rule them all"
→ Use moirai20-small
   - Best overall accuracy
   - Fastest neural inference
   - Best calibration
   - No multivariate poisoning issues
   - Setup: venv_moirai with uni2ts + gluonts 0.14.x

SCENARIO B: "I want the absolute best temperature forecast"
→ Use toto-22m-mv for temperature ONLY
   - Then fall back to moirai20-small for all other fields
   - This hybrid approach gives you the best of both worlds

SCENARIO C: "I need minimum latency and can tolerate heuristics"
→ Use seasonal_naive for wind_direction + persistence for everything else
   - BUT: swap to moirai20-small or toto-22m for irradiance
   - Never use persistence for solar forecasting

SCENARIO D: "I want to run everything in one venv"
→ Use toto-22m (univariate)
   - No need for separate venv_moirai
   - Consistent, solid performance across all fields
   - Supports multivariate when sensors are clean

================================================================================
CRITICAL WARNINGS
================================================================================

1. ECCC DATA OVERLAP: The benchmark uses public ECCC data. Chronos and TimesFM
   may have seen similar data during pretraining. Treat their MASE as optimistic.
   Validate on YOUR actual sensor stream before production deployment.

2. WIND DIRECTION: All neural models struggle here. The code already falls back
   to circular persistence for wind_direction in the pipeline mode — this is
   intentional and correct. Don't waste GPU cycles on wind direction.

3. IRRADIANCE PHYSICS: All neural models get the clear-sky residual post-processing.
   This means their irradiance scores are boosted by physics, not pure ML.
   The real test is whether they predict the kt (clearness index) correctly.

4. HUB_VOLTAGE IS SYNTHETIC: It's RNG noise. Any model scoring < 1.0 MASE is
   just getting lucky. Don't read too much into hub_voltage rankings.
